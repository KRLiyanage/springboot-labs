# Spring Boot Lab Worksheets

This repository contains my practical implementations and solutions for the Spring Boot Lab worksheets. Each folder represents a specific lab session covering different concepts of the Spring Boot framework.

## 🛠️ Tech Stack & Tools
*   **Java** (version 17 or higher)
*   **Spring Boot** (Spring Web, Spring Data JPA, Spring Security)
*   **Build Tool:** Maven / Gradle
*   **Database:** MySQL / H2 (as required per lab)
*   **IDE:** IntelliJ IDEA / STS / VS Code

## 📁 Repository Contents
*   **Lab 01:** Introduction to Spring Boot & Project Architecture
*   **Lab 02:** Creating RESTful APIs (CRUD Operations)
*   **Lab 03:** Working with Spring Data JPA & Databases
